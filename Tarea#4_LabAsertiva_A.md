# Estrategia de Comunicación Asertiva para Equipos de Desarrollo Remoto
#202500708
#202230781

## Resumen

Esta propuesta busca estructurar los flujos de comunicación de un equipo de desarrollo de software que trabaja de forma virtual, reduciendo el ruido informativo y mejorando la trazabilidad de decisiones mediante comunicación asertiva, herramientas de GitHub y protocolos claros para reuniones y contingencias.

## Puntos clave de la propuesta

- **Netiqueta y prioridades:** comunicación asíncrona por defecto, uso obligatorio de hilos para no saturar el canal principal, y 3 niveles de prioridad (alta, media, baja) con tiempos de respuesta definidos.
- **Herramientas colaborativas:** GitHub Issues para reportar bugs y tareas, Pull Requests con revisión de código constructiva, y Wiki como fuente única de verdad del proyecto.
- **Ownership documental:** cada documento o artefacto técnico tiene un responsable (Document Owner) encargado de mantenerlo actualizado.
- **Roles en reuniones remotas:** un moderador que guía la agenda y da la palabra, y un timekeeper que controla los tiempos por punto de la agenda.
- **Plan de fallback:** protocolo de migración a canal alterno ante fallas de videollamada (máx. 5 min), y notificación asíncrona ante fallas individuales de conexión.
